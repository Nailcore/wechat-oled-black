# 微信纯黑 OLED

> 本仓库对应模块版本 `1.5.23`。恢复后的源码已使用 Android SDK 36、Java 编译器和 D8 完成静态构建验证。

本项目为非官方项目，与腾讯或微信没有隶属或背书关系；相关商标归其权利人所有。本仓库不包含第三方应用源码。

一个面向 LSPosed 的 Android 主题模块，用于在微信深色模式下调整部分背景，并为部分文章页面提供深色适配。模块不会上传页面内容；适配效果取决于页面实现和系统主题。

## 兼容性

- Android 9（API 28）及以上；需要可用的 LSPosed / Xposed 兼容环境。
- 当前适配以微信 8.0.76 为目标；不同版本、页面或系统可能不生效。可选的渲染探针需要 Android 13 及以上，无法启用时会安全跳过。
- 日间模式应保持原有显示；文章分隔位置的处理依赖页面结构，不保证所有文章一致。升级或主题切换后可能需要重启微信。

## 构建

需要 JDK 17 或更新版本、Android SDK 36、Gradle 8.9 或兼容版本，以及 Android Gradle Plugin 8.7.3。Xposed API 82 仅作为 `compileOnly` 依赖，不会打包进 APK。配置 `ANDROID_HOME` 或本地 `local.properties` 后，在工程根目录运行：

```shell
gradle :app:assembleDebug
```

调试构建仅用于测试；发布版本需要维护者使用自己的签名配置。不要提交密钥或本地 SDK 配置。

## 安装

安装自己构建的 APK，在 LSPosed 中启用模块并勾选微信作用域，然后重启微信。覆盖安装要求签名与已安装版本一致；签名不同的情况请先自行备份并评估系统提示。

## 设置与更新

从启动器或 LSPosed 的模块设置入口可打开设置页，页面保留“一键重启微信”功能，并提供 Release、源码、反馈和 MIT 许可证链接。

“检查更新”仅在用户手动点击后，通过 HTTPS 请求 GitHub Releases 的 latest 接口以读取版本信息和 Release 链接；不会自动下载或安装，也不会收集、上传聊天或页面内容。

## 限制与反馈

本项目仅调整界面主题，不提供绕过限制、敏感页面处理或数据采集功能。请勿在反馈中提交聊天、文章内容、账号信息或设备标识。请参阅 [SECURITY.md](SECURITY.md) 和 [CONTRIBUTING.md](CONTRIBUTING.md)。
